# Chatting_App

A full-stack chat application with a Laravel backend and a Flutter frontend.

This repository contains two main parts:

- `backend/` — Laravel API and chat server implementation.
- `frontend/` — Flutter client application for mobile and web.

## Repository Structure

- `backend/` — Laravel project with models, migrations, notifications, and real-time chat support.
- `frontend/` — Flutter project that connects to the backend and provides the mobile chat UI.
